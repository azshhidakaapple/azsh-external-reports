# azsh-external-reports

[azsh.uk](https://azsh.uk/) / ICAT に対する**外部評価・外部検証レポート**の恒久置き場です。

## このリポジトリについて

- レポートの著者は外部検証担当 (Muse) であり、azsh.uk / ICAT の内部チームとは独立に作成されています。
- 外部検証は完全に外部からの評価です。対象コードへの変更は一切行いません (読み取り専用)。
- 各レポートは、公開データと (開示された場合は) 公開コードのみを用いて再現可能な形で書かれています。
- これらのレポートは投資助言ではありません。
